This repo has some helper functions and classes that are useful when working on coding puzzles like [Advent Of Code](https://adventofcode.com), [EveryBody Codes](https://everybody.codes), or [Systems Check](https://systemscheck.dev).

It is used in some of my solution repos like https://github.com/nkiesel/AdventOfCode_2025 or https://github.com/nkiesel/EverybodyCodes_2026.
